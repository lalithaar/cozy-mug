---
title: "Routing API"
description: "Router methods and named routes."
---

Methods: `Get`, `Post`, `Put`, `Patch`, `Delete`, `Head`, `Options`, `Any`,
`Handle`, `Group`, `Static`, `StaticFS`, `Mount`, `NotFound`.

Additional features: named routes (`As`), reverse URLs (`Path`), middleware
(`Use`), and canonical-slash handling (`DisableCanonicalSlash`).
