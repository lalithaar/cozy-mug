# cozy-mug v0.0.11 (pre-release)

Patch release focused on closing the Default UI item around semantic HTML +
inherent.css.

## Highlights
- Default UI styling now comes from a vendored copy of inherent.css
  (`ui/static/base.css`, served at `/static/ui/base.css`); the old custom token
  stylesheet is gone.
- Scaffolds no longer ship `static/style.css`; they only link the UI stylesheet.
- `ui` package docs/comments and tests refreshed for the new base stylesheet.

## Docs/status
- Roadmap marks **Default UI** complete.
- AGENTS/README updated so only getting-started/docs polish and the testing
  convention remain for v0.1.

## Notes
- Still pre-release; v0.1.0 is not cut yet because getting-started/docs polish
  and the testing convention remain.
