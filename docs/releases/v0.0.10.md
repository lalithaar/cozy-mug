# cozy-mug v0.0.10 (pre-release)

Patch release focused on finishing the model→migration generator.

## Highlights
- `cozy migrate new` now discovers structs embedding `data.Model` in the source tree, parses their `db` tags, and emits real per-dialect DDL into `migrations/sqlite/` and `migrations/postgres/` instead of stubs.
- Falls back to a writing a stub when no models are found, preserving the manual path for migrations the generator cannot derive.
- `cozy` CLI version and scaffolded `go.mod` dependency bumped to `v0.0.10`.

## Docs
- README and AGENTS status synced to the shipped generator.
- Roadmap marks the data migration generator complete; only the live Postgres data test remains in that area.

## Notes
- Still pre-release; `v0.1.0` gates on Default UI components, getting-started polish, testing convention, and the live Postgres test.
